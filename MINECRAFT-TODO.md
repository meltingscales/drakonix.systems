# Minecraft SMP servers to check out

Unique/strange picks (skyblock, economy, automation) based on GregTech/StoneBlock/Agrarian Skies taste.

- [mineinabyss.com](https://mineinabyss.com/) - Made in Abyss-themed SMP, custom plugins/mechanics around the anime's abyss/curse concept. Very unique gimmick server.
- [GTNH multiplayer servers](https://gtnewhorizons.com/) - GregTech New Horizons on a shared world. Same brutal tech tree as GregTech modpack, but with other players racing/competing for resources.
- [Create: Above and Beyond](https://www.curseforge.com/minecraft/modpacks/create-above-and-beyond) SMP servers - skyblock where progression = building bigger Create contraptions. Automation-as-gameplay.
- [Complex Gaming](https://complexminecraft.com/) - modded server network (Vault Hunters, custom modpacks) with real economy/market systems between players.
- [EarthMC](https://earthmc.net/) - vanilla-ish nation/economy server on a 1:1000 scale real-world map. Politics, trade routes, player-drawn borders.
- [CivMC](https://civmc.net/) - anarchy-adjacent civilization server: no admin-enforced rules, factions build nations/currency/diplomacy themselves.
- [2b2t](https://2b2t.org/) - original anarchy SMP since 2010. Not automation-focused, but strangest Minecraft culture/history around.
- SkyFactory 4/5 dedicated servers (check Aternos/hosting lists) - skyblock + automation, same lineage as Agrarian Skies/StoneBlock but with other players to trade/compete with.
